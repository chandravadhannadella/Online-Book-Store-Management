About Us

The Online Book Store Management System is a simple web application developed using HTML and CSS.

It provides an easy way for users to browse books, sellers to manage book details, and administrators to maintain the system.

This project demonstrates the basic concepts of web page design, navigation, registration forms, and user interaction using HTML and CSS.

Our aim is to make book purchasing simple, fast, and convenient for buyers while giving sellers an easy platform to manage their books.
